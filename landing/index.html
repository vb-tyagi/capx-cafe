Before you settle in

A few
good questions.

Is capx café free?

The developer BYO lane is free on capx café’s side. You bring your own X developer app and pay X directly for API usage. Self-hosting also involves your own infrastructure costs. The creator lane will be a separate paid beta.

Can I use it with my agent?

capx café runs as a stdio MCP server. Claude Code, Cursor, Codex, Windsurf, Cline, and other compatible MCP clients can use its tools. Claude Code has a bundled plugin; the repository includes skill adapters for Cursor, Codex, and Windsurf. Docker Desktop works through capx café’s custom MCP catalog.

Does capx café read my repository?

Your coding agent uses the context you give it. The capx café service receives the post text you route through its publishing tools; it does not receive general access to your repository, files, or other apps. Your agent’s own privacy settings still apply. See what the service can and cannot see.

Will scheduled posts run with my laptop closed?

Yes. Queued posting loops run on the server. Your agent prepares the posts; the server publishes them on schedule, subject to guardrails and account eligibility. Loops require a verified X account that is at least 30 days old. Universal safety limits are 10 posts/hour and 40/day.

What does the guardrail check?

casserole applies deterministic checks for eligibility, rate limits, text quality, authenticity, kill-switch state, and audit. A post may pass, need a rewrite, be held, or be blocked. It checks caption text; attached images and videos are not content-moderated. Read the full security model and its limits.

Can I run it on my own infrastructure?

Yes. The server is open source under AGPL-3.0; the client and skills use MIT. You can run the server with your own X app, database, keys, and domain. Read the self-hosting guide.
